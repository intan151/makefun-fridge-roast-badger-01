## The entry

`main.py` writes one roast line (163 characters) about a smart fridge to
`/output/entry.txt`, then self-checks that the written file is byte-identical
to the entry, 1–200 characters, and not only whitespace.

> My smart fridge pushed a firmware update at 3 a.m., rebooted for twenty
> minutes, then proudly announced the milk expired — three days after it
> watched me drink it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
